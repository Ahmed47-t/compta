# نطاق المشروع (SCOPE.md)

**المشروع:** PC COMPTA Next (`Ahmed47-t/compta`)  
**الإصدار:** 1.0 — يوليو 2026  
**الهدف:** تحديد النطاق الوظيفي والتقني الدقيق للإصدار الأول (`V1.0 MVP / Complete Desktop Suite`) والفصل الحاسم بين ما هو داخل النطاق (`In-Scope`) وما هو خارجه (`Out-of-Scope`).

---

## 1. داخل النطاق (In-Scope — V1.0 Desktop Release)

### 1.1 إدارة الهيكل والتأسيس المحاسبي (`Configuration & Setup`)
- **الملفات والشركات (`Companies/Dossiers`):** إنشاء الملفات المحاسبية مع حفظ البيانات الأساسية والجبائية كاملة (`NIF, NIS, RC, Article Imposition, Adresse, Devise`).
- **السنوات المالية (`Exercices`):** إنشاء وإدارة فترات السنين المحاسبية، وتدعم تشغيل أكثر من سنة بالتوازي (`Multi-exercices en parallèle: مثلاً 2024 و 2025 مفتوحين معاً`).
- **دليل الحسابات (`Plan Comptable`):** إدارة الحسابات بمرونة (كود حتى 14 خانة رقمية أو حرفية)، تصنيفات الحساب (`Lettrable, Soumis à Auxiliaire, Analytique`)، وقوالب جاهزة حسب النظام المحاسبي المالي الجزائري (`SCF 2007/2026`).
- **اليوميات (`Journaux`):** إنشاء عدد غير محدود من اليوميات بأكواد (8 أحرف) وتحديد طبيعتها (`Achats, Ventes, Banque, Caisse, Opérations Diverses, Ouverture`).
- **الحسابات المساعدة (`Auxiliaires`):** دفتر العملاء (`411`) والموردين (`401`) مع ربط كل حساب ببياناته الضريبية.

### 1.2 إدخال الحركات ومحرك القيود (`Saisie & Core Engine`)
- **نظام إدخال اليومية بنظام الفوليو (`Saisie par Folio`):** تقسيم إلزامي لكل شهر بـ `Folio` مستقل (`Folio 01 = جانفي` حتى `12 = ديسمبر`، زائد الفوليو الخاص بالافتتاح والإغلاق)، وترقيم أسطر تلقائي (`LIGNE`).
- **التحقق الرباعي الفوري (`Real-time Validation`):**
  1. تطابق تاريخ القيد (`SDATE`) مع شهر الفوليو الفعال.
  2. التحقق من وجود وصلاحية الحساب المحاسبي (`CODE_COM`).
  3. التحقق الإلزامي من وجود الحساب المساعد (`CODE_AUX`) للحسابات التي تتطلب ذلك (`Soumis à Auxiliaire`).
  4. التحقق من توازن الفوليو (`Total Débit = Total Crédit`) قبل السماح باعتماده وإغلاقه.
- **إدارة التعديل والتصحيح (`Corrections & Audit`):**
  - منع الحذف أو التعديل المباشر لأي قيد تم اعتماده (`Posted / Validé`).
  - دعم القيود العكسية (`Contre-passation`) والقيود السالبة (`Saisie Négative`).
  - دعم التصحيح المبرر (`Correction avec motif`) في القيود غير المغلقة، مع الحفظ الإلزامي في سجل التدقيق المقاوم للحذف (`Audit WORM Log`).
- **الافتتاح ونقل الأرصدة (`Journal d'Ouverture & Report à-nouveaux`):** نقل الأسطر غير المطابقة (`Non lettrées`) بالتاريخ والرقم الأصلي لمتابعة الديون وأعمارها بدقة.

### 1.3 المطابقة والتحليل (`Reconciliation & Analytical Accounting`)
- **المطابقة (`Lettrage`):** مطابقة يدوية وآلية للقيود بالاعتماد على المبالغ ورقم الفاتورة مع الترقيم الأبجدي التلقائي (`AA, AB, AC...`) وإصدار كشوف الأرصدة غير المطابقة.
- **المحاسبة التحليلية والميزانياتية:** دعم 3 محاور تحليلية ومقارنة الميزانية التقديرية (`Prévisionnel`) بالفعلي (`Réalisé`) وتحديد الفروقات.

### 1.4 الأصول والاهتلاكات (`Immobilisations & Amortissements`)
- تسجيل الأصول وإدارة تاريخ الاقتناء وتاريخ بدء الخدمة، مع فصل فارق إعادة التقييم (`Écart de réévaluation - المادة 44`).
- حساب أقساط الاهتلاك الخطي (`Amortissement Linéaire`) وتوليد قيود الاهتلاك السنوية تلقائياً.

### 1.5 محرك التقارير والجباية (`Reporting & Tax Formula Engine`)
- إصدار التقارير الأساسية: اليوميات العام، دفتر الأستاذ (`Grand Livre`)، وميزان المراجعة (`Balance`).
- مترجم الصيغ الجبائية (`Dictionnaire des Formules Compiler`): تحليل وتنفيذ الصيغ الجزائرية (`-SOLDE(10)`, `CRD`, `/DEB`) بسرعة وكفاءة.
- تصدير التقارير الجبائية الأساسية (`G50`، كشوفات `TVA`، وجداول الميزانية والحزمة الجبائية الأساسية `Liasse Fiscale`).

### 1.6 محرك الـ OCR المحلي لاستخراج الفواتير (`Offline OCR Worker Service`)
- استقبال ملفات PDF والصور الممسوحة ضوئياً (`WIA/TWAIN/Upload`).
- معالجة محلية بنسبة 100% باستخدام PaddleOCR + TrOCR + LayoutLMv3 لاستخراج حقول الفاتورة (`المورد، NIF، رقم الفاتورة، التاريخ، HT، TVA، TTC`).
- خوارزمية اقتراح ذكي للقيد ومطابقة المبالغ (`TTC == HT + TVA`).
- واجهة مراجعة وتحقق إلزامي (`Validation UI`) تمنع الترحيل التلقائي وتتطلب تأكيد المحاسب.

### 1.7 الهجرة والاستيراد والتصدير (`Migration & Data Exchange`)
- استيراد وهجرة ملفات قاعدة بيانات PC COMPTA القديمة (`.DLG` بصيغة DBF) مع الحفاظ على التواريخ وحالة القيود.
- قراءة واستيراد ملفات الفوليو الخارجية (`.PCC` SDF Fixed-length format).
- استيراد وتصدير الجداول والموازين والقيود عبر ملفات `Excel/CSV`.

### 1.8 الأمان والحوكمة والتشغيل (`Security & Operation Engine`)
- تطبيق سطح مكتب متوافق مع Windows 10/11، يتميز بسرعة استجابة فائقة بفضل `Keyboard-First UX`.
- أمان بنكي: تشفير البيانات محلياً بـ `AES-256`، التحكم بالوصول `RBAC/RLS`، سجل تدقيق مقاوم للمحو (`WORM Audit Append-Only`)، وسلسلة تجزئة للقيود (`Hash Chain`).
- نظام النسخ الاحتياطي التلقائي والمشفر واستعادة الكوارث (`Backup 3-2-1-1-0`).
- نظام ترخيص رقمي موقع تشفيرياً بـ `RSA` مرتبط بـ `Hardware Fingerprint` ويغني عن أجهزة الـ Dongle.

## 2. خارج النطاق (Out-of-Scope — Non-Goals for V1.0)

1. **الذكاء الاصطناعي الحواري (`Chatbot LLM Assistant`):** لا يتم بناء أو تضمين مساعد دردشة بالـ AI داخل التطبيق استجابة لطلب العميل وحفاظاً على الأداء والخفة؛ الذكاء الاصطناعي محصور في استخراج الفواتير بالـ OCR.
2. **التشغيل السحابي الإلزامي (`Pure SaaS / Web-only App`):** النظام ليس تطبيق ويب تتطلب إدارة الحسابات فيه اتصالاً بالإنترنت؛ النظام يعمل `Offline-First` بشكل كامل.
3. **التكامل المباشر والآلي مع خوادم الضرائب (`Direct Automated DGI API Integration`):** لا تفترض المرحلة الحالية وجود API مفتوح من طرف مديرية الضرائب الجزائرية (`DGI`)؛ يتم الاكتفاء بتوليد النماذج والتقارير بصيغ `PDF/Excel` المطابقة رسمياً للرفع أو التقديم.
4. **المحاسبة المتعددة المعايير (`IFRS / GAAP Generic Multi-Country`):** النظام مصمم ومحسن حصرياً للنظام المحاسبي الجزائري (`SCF 2007/2026`) ولا يدعم في V1 معايير دول أخرى غير جزائرية.
5. **التعزيز السحابي التلقائي للـ OCR (`Automatic Cloud OCR Fallback`):** في V1، يعمل الـ OCR محلياً فقط. ميزة الربط السحابي الاختياري (`Cloud Fallback`) والتعلم النشط (`Active Learning`) مؤجلة للمرحلة 13 بعد اجتياز الإطلاق التجريبي وموافقة الخصوصية.
