# مواصفات المرحلة 06: واجهة الإدخال Keyboard-First (PHASE-06.md)

**المرحلة:** Phase 06  
**الخبير المطلوب:** Principal UX Engineer للأنظمة المالية + Accessibility Specialist  
**الهدف الأساسي:** تصميم وتطوير واجهة مستخدم سطح المكتب (`Tauri + React + TypeScript + Tailwind`) بتركيز استثنائي على السرعة والتحكم الكامل بـ Keyboard ومحاكاة سلاسة برنامج PC COMPTA الأصلي.

---

## 1. نطاق العمل المطلوب (Scope of Work)

1. **نظام التصميم ثنائي اللغة (`Bilingual Design Tokens`):** بناء مكونات تدعم التبديل السلس بين العربية والفرنسية والاتجاهين (`RTL / LTR`).
2. **محدد الملفات والفترات (`Company & Exercice Selector`):** شاشة اختيار الشركة والسنة المالية وإدارة الفترات المفتوحة والمغلقة بسرعة.
3. **شبكة الإدخال الافتراضية السريعة (`Saisie Virtualized Grid`):** جدول يحاكي واجهة PC COMPTA، قادر على عرض وتمرير آلاف السطور في الفوليو دون تباطؤ (`60 FPS`).
4. **خريطة الاختصارات الإلزامية (`Keyboard Map`):**
   - `Tab / Shift+Tab`: التنقل السلس بين الخانات.
   - `Enter`: تأكيد القيد والانتقال للسطر التالي.
   - `Esc`: التراجع أو إلغاء الإدخال.
   - `F2`: فتح نافذة بحث فوري في دليل الحسابات (`Plan Comptable`).
   - `F3`: فتح نافذة بحث فوري في الحسابات المساعدة (`Auxiliaires`).
   - `F9`: توازن الفوليو التلقائي وإدراج سطر الموازنة.
5. **إدارة الأخطاء والحفظ التلقائي (`Inline Validation & Draft Autosave`):** إظهار التنبيهات الفورية عند عدم التوازن أو اختلاف شهر الفوليو، وتفعيل الحفظ التلقائي للمسودات (`Draft Only`) لمنع فقدان العمل، دون الاعتماد أو الترحيل الضمني.
6. **اختبارات المكونات والأداء (`Component & E2E Tests`):** قياس استجابة البحث (`< 50ms`) واستجابة التمرير وتضمين لقطات وتوثيق للرحلات الحرجة.

---

## 2. بوابة القبول (Acceptance Gate)

- تمكن محاسب محترف من إتمام سيناريو شراء أو بيع كامل دون لمس الفأرة تقريباً.
- خلو الشاشات من مصائد لوحة المفاتيح (`Keyboard Traps`) أو التعديلات المالية الغامضة دون تأكيد.
- زمن استجابة البحث والحفظ يقع ضمن الميزانيات الزمنية المعتمدة (`P95 within CPU budget`).
