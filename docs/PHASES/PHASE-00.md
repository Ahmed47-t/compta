# مواصفات المرحلة 00: تأسيس ذاكرة المشروع وحوكمة GitHub (PHASE-00.md)

**المرحلة:** Phase 00  
**الخبير المطلوب:** Principal Software Architect + Technical Program Manager  
**الهدف الأساسي:** تحويل مستودع GitHub إلى مصدر حقيقة منظم، دائم، ومستقل (`Permanent Project Memory`) قبل كتابة أي كود منتج أو ميزة محاسبية.

---

## 1. نطاق العمل المطلوب (Scope of Work)

1. **إنشاء وتحسين قواعد العمل (`AGENTS.md`):** تعريف قواعد إلزامية لجميع وكلاء الذكاء الاصطناعي (`AI Agents`) وحوكمة الفروع وفحص حالة المستودع.
2. **تأسيس هيكلة التوثيق (`docs/ Structure`):** إنشاء مستندات الرؤية (`PRODUCT_VISION.md`)، المخطط الرئيسي (`MASTER_PLAN.md`)، النطاق (`SCOPE.md`)، قاموس المصطلحات (`DOMAIN_GLOSSARY.md`)، القيود المحاسبية (`ACCOUNTING_INVARIANTS.md`)، معايير القبول (`ACCEPTANCE_CRITERIA.md`)، مصفوفة التتبع (`TRACEABILITY_MATRIX.md`)، وسجل المخاطر (`RISK_REGISTER.md`).
3. **تأسيس حوكمة القرارات (`docs/DECISIONS/`):** إنشاء قالب القرارات المعمارية (`ADR Template`) ووثيقة القرار المعماري الأساسي (`ADR-0001-architecture.md`).
4. **تأسيس مجلدات وحوكمة المراحل (`docs/PHASES/ & docs/HANDOFF/`):** إنشاء مواصفات المراحل من `PHASE-00.md` حتى `PHASE-14.md`، وقوالب تقارير المراحل، وملفات حالة التسليم اللحظية (`CURRENT_STATE.md, LAST_PHASE_REPORT.md, OPEN_QUESTIONS.md, NEXT_PHASE_INPUT.md`).
5. **تأسيس مجلدات الأمان والاختبار والتشغيل (`SECURITY/, TESTING/, RUNBOOKS/`):** إعداد ملفات خط الأساس الأمني ونموذج التهديدات واستراتيجيات الاختبار وأدلة التشغيل.
6. **إنشاء قوالب GitHub وسجل التغييرات (`.github/ & CHANGELOG.md`):** إنشاء قوالب الـ Issues والـ Pull Requests وسجل التغييرات الموحد.

---

## 2. بوابة القبول ومعايير النجاح (Phase 00 Gate & Definition of Done)

- يمكن لأي مطور أو `AI Agent` جديد الدخول للمستودع وفهم الرؤية والنطاق والمشروع وحالته والخطوة التالية مباشرة دون الحاجة للرجوع لسجل محادثات سابقة.
- وجود كل المتطلبات المحاسبية الحساسة (`ACCOUNTING_INVARIANTS.md`) ومصفوفة التتبع (`TRACEABILITY_MATRIX.md`) موثقة بدقة.
- استخراج جميع الأسئلة غير المحسومة إلى `OPEN_QUESTIONS.md` (مثل تفاصيل النماذج الرسمية وسياسات السحابة والأجهزة الدنيا).
- عدم احتواء المرحلة على أي كود برمجي أو ميزات وظيفية مسبقة لآوانها.
