# مواصفات المرحلة 14: التقارير الجبائية الرسمية المتقدمة والتكامل (PHASE-14.md)

**المرحلة:** Phase 14  
**الخبير المطلوب:** Tax Software Architect + خبير جباية وضرائب جزائري معتمد  
**الهدف الأساسي:** بناء وتوليد التقارير والنماذج الضريبية الرسمية المتقدمة لمديرية الضرائب الجزائرية (`DGI`) مع اعتماد الصيغ المحدثة وتواريخ السريان الجبائي.

> **ملاحظة حاسمة:** لا تُبدأ هذه المرحلة في كتابة الكود إلا بعد جمع وإيداع المراجع والنماذج الرسمية المحدثة داخل المستودع والتحقق القانوني منها.

---

## 1. نطاق العمل المطلوب (Scope of Work)

1. **إيداع المراجع الضريبية الرسمية (`Official Tax Reference Repository`):** جمع القوانين والتوجيهات الجبائية الجزائرية الصادرة والمصرح باستخدامها وتوثيق رقم وإصدار كل مرجع.
2. **مصفوفة المتطلبات الجبائية (`Legal/Tax Requirements Matrix`):** إعداد وثيقة مفصلة تربط كل خانة وحقل في النماذج الضريبية بالمادة القانونية وصيغة الحساب وتوقيع الخبير المحاسبي.
3. **توليد النماذج الرسمية (`Advanced G50 & Liasse Fiscale Output`):** إنتاج ملفات PDF مطابقة تماماً للنماذج الرسمية الورقية لمديرية الضرائب (جداول الميزانية، حسابات النتائج، تغيرات الأموال الخاصة، وجداول الاهتلاك والالتزامات)، وتصدير جداول Excel دقيقة.
4. **تواريخ السريان وأعلام التفعيل (`Effective Dates & Feature Flags`):** دعم تغير النسب الضريبية وقوانين المالية عبر التواريخ (مثلاً: تطبيق نسبة TVA معينة لسنوات سابقة ونسبة جديدة بعد تاريخ محدد) دون تعديل الكود الأساسي.
5. **التكامل الإلكتروني أو واجهة المحاكاة (`Electronic Tax Filing Interface / Mock`):** توفير التصدير الإلكتروني إن وُجدت وثائق API رسمية من DGI، أو الاكتفاء بواجهة تصدير قياسية وتوثيق غياب الـ API الرسمي لعدم ادعاء تكامل غير حقيقي.

---

## 2. بوابة القبول (Acceptance Gate)

- كل خانة ورقم في نماذج `G50` والحزمة الجبائية (`Liasse Fiscale`) مرتبطة بمرجع رسمي وصيغة واختبار وتوقيع معتمد من الخبير الجبائي.
- تطابق المخرجات بنسبة 100% مع النماذج الذهبية والمقارنة مع الحسابات اليدوية المعقدة.
