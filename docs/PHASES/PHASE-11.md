# مواصفات المرحلة 11: الأمن والنسخ والاسترجاع والترخيص (PHASE-11.md)

**المرحلة:** Phase 11  
**الخبير المطلوب:** Security Architect + Windows Release Engineer  
**الهدف الأساسي:** تحصين النظام وتقوية الدفاعات الأمنية (`System Hardening & Cryptographic Protection`) قبل إطلاق الإصدار التجريبي على حواسيب المكاتب.

---

## 1. نطاق العمل المطلوب (Scope of Work)

1. **تحديث نموذج التهديدات وحالات إساءة الاستخدام (`Threat Model & Abuse Cases`):** توثيق سيناريوهات الهجمات المحلية ومحاولات سرقة قواعد البيانات أو تخطي الصلاحيات.
2. **المصادقة وإدارة الأسرار (`Argon2id, MFA & OS Keychain`):** فرض خوارزمية `Argon2id` لتجزئة كلمات المرور، ودعم المصادقة المتعددة العوامل (`MFA`) للأدوار الحساسة، وحفظ مفاتيح التشفير بأمان في `Windows Credentials / OS Keychain`.
3. **تشفير وسلسلة أختام الإغلاق (`Cryptographic Seals & RSA Signature`):** إتمام نظام التوقيع المشفر للسنوات المالية (`Exercice Seals`) عند الإغلاق النهائي، لضمان اكتشاف أي تعديل خارجي في قاعدة البيانات.
4. **نظام النسخ الاحتياطي المشفر (`Encrypted Backup 3-2-1-1-0 Engine`):** جدولة وتوليد نسخ احتياطية دورية مشفرة بـ `AES-256` مع ضغط وحفظ التجزئة (`Checksums`) وحماية النسخة ضد التعديل (`Immutable Snapshot`).
5. **استعادة الكوارث وتجربة الاسترجاع (`Disaster Recovery & Clean Restore`):** بناء واجهة وآلية استعادة آمنة تختبر التحقق من سلامة النسخة وتجزئتها قبل استرجاعها على بيئة نظيفة.
6. **نظام الترخيص الرقمي المؤمن (`RSA Signed Licensing`):** استبدال أجهزة الـ Dongle بنظام ترخيص رقمي موقع بـ `RSA Private Key`، يربط البصمة العتادية للمكتب (`Hardware Fingerprint`) بحالة الشركة ويدعم سياسة تشغيل غير متصلة مرنة (`Graceful Offline Policy`).
7. **بناء وتوقيع حزم التثبيت (`Signed Windows NSIS Installer`):** إعداد حزمة تثبيت للويندوز ونظام تحديث تلقائي وتراجع آمن (`Auto-Updater & Rollback`).

---

## 2. بوابة القبول (Acceptance Gate)

- نجاح عملية النسخ الاحتياطي المشفر والاستعادة الكاملة على جهاز نظيف وتطابق أرقام التجزئة (`Zero Difference Recovery`).
- عدم وجود أي ثغرة أمنية حرجة أو عالية الخطورة (`No Open Critical/High Vulnerabilities`).
- نجاح تثبيت وتحديث التراخيص والتحقق من أختام الإغلاق على بيئات Windows دون الحاجة للاتصال بالإنترنت.
