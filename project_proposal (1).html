  • ضعف القوة الشرائية

12. حل OCR - PaddleOCR + OpenVINO

⚠️ لماذا هذا الحل؟

  • PaddleOCR: محرك OCR قوي ومجاني يدعم العربية
  • OpenVINO: تسريع على معالجات Intel بدون GPU
  • Offline: يعمل بدون إنترنت
  • Fast: قراءة فاتورة في أقل من 3 ثوانٍ
  • Private: كل البيانات تبقى محلياً

12.2 خطوات التطوير

Step 1: تصدير النموذج من PaddlePaddle إلى ONNX

python tools/export_model.py \
  -c configs/det/det_mv3_db.yaml \
  -o Global.pretrained_model=./pretrain_models/ch_PP-OCRv4/ \
  -o Global.save_inference_dir=./inference_model

Step 2: تحويل ONNX إلى OpenVINO

mo --input_model ocr_model.onnx \
  --output_dir openvino_model \
  --data_type FP32

Step 3: تحويل إلى .exe

# PyInstaller (أسهل)
pip install pyinstaller
pyinstaller --onefile --windowed ocr_backend.py

# أو Nuitka (أسرع)
pip install nuitka
nuitka --standalone ocr_backend.py

12.3 Parser - استخراج البيانات

def parse_invoice(text: str) -> dict:
    # البحث عن المبلغ
    amount_pattern = r'(\d{1,3}[,\s]?\d{3}[,\s]?\d{3})'
    amounts = re.findall(amount_pattern, text)
    total = float(amounts[-1].replace(',', '')) if amounts else 0
    
    # البحث عن التاريخ
    date_pattern = r'(\d{1,2}[/\-]\d{1,2}[/\-]\d{2,4})'
    dates = re.findall(date_pattern, text)
    invoice_date = dates[0] if dates else ""
    
    # البحث عن رقم الفاتورة
    invoice_pattern = r'(?:فاتورة|Facture|Invoice)[#\s]*(\w+)'
    invoice_match = re.search(invoice_pattern, text)
    
    return {
        "vendor": extract_vendor(text),
        "date": invoice_date,
        "amount": total,
        "invoice_number": invoice_match.group(1) if invoice_match else "",
        "raw_text": text
    }
